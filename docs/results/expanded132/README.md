# Expanded 132-series research protocol

The new [protocol resource](../../../src/simfolio_forecasting_methodology/resources/protocols/portfolio80_asset52_equal_weight_v1.yaml) preserves the exact frozen 80-portfolio experiment and adds the sorted union of its 52 actual tickers as 100% single-asset holdings. It defines a separate score: **0.5 × original80 mean CRPS + 0.5 × single52 mean CRPS**. This gives each block equal weight; averaging all 132 series would answer a different question. Original80 scores and legacy ranking semantics remain unchanged.

Both blocks use the same price-derived logs, 1979-12-31 through 2026-05-13 (11,687 rows), 48 rolling origins plus three temporal holdouts per series, 240 paths, and every eligible daily horizon through 8,766 days. The original block has 4,080 tasks and 701,280 cells; single52 has 2,652 tasks and 455,832 cells. CRPS targets terminal log returns with the exact empirical n-squared pairwise denominator. Origin losses are averaged within each series/horizon cell, then cells within each block. Missing/nonfinite vectors or incomplete denominators fail closed.

The [machine-readable report](score-report.json) binds the protocol, complete result files, manifests, ranked full-cell arrays and independent audit receipts by SHA-256. Compressed manifests decompress to the original JSON bytes, preserving both their file hashes and canonical manifest hashes. The stationary-OU original80 manifest is an explicitly attested portable derivative: only its cache location is normalized. Its public file hash differs from the original file hash and original checkpoint semantic digest; removing the cache-location field yields the recorded invariant numerical-identity fingerprint. Original80 incumbent evidence is referenced in its existing retained artifact, without copying or modifying it. Partial control cell checksums remain bound to their result receipts; their bulk checkpoints are retained in the verified numerical archive linked below.

## Corrected naive benchmark

For future expanded OOS comparisons, **naive benchmark** means the whitepaper joint raw-return stationary bootstrap, `asset_level_naive_politis_white_stationary_bootstrap_rebalanced`. It uses the exact retained engine Politis–White return/squared-return rule and original seed contract, shared asset-row sampling, and policy-aware holdings rejoining. It is distinct from both the portfolio IID bootstrap and the asset-level Default model. The earlier `rawsbb` screen used `arch.bootstrap.optimal_block_length`, so its score is not this comparator.

The [completed benchmark](whitepaper-naive/aggregate.json) scores **0.3819285166552024** on original80, **0.8471738853754932** on single52, and **0.6145512010153478** on the 50/50 aggregate. All 6,732 origin vectors were independently reaggregated and all 1,157,112 cells/counts matched exactly. Original80 reproduces the retained whitepaper score exactly; all 8,766 historical horizon means match within 8.89e-16. The benchmark was rerun on both complete blocks; the historical rounded 0.382 was not reused.

Against this matched expanded benchmark, M262 has **33.6396620556%** lower CRPS and M261 has **31.6092240822%** lower CRPS. M262 improves over M261 by **2.9688769373%**. On original80 alone, the corresponding reduction versus naive is about 42.36%, which is a different comparison. The [evidence index](whitepaper-naive/files.json) binds both full cell arrays, original manifests, execution source revision, smoke gates and historical reproduction audit. No production model was changed.
