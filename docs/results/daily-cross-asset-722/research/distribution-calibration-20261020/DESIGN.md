# Descriptive calibration check; canonical model scoring unchanged

Purpose: identify where the current portfolio-series winner's predictive
distributions are poorly calibrated, to motivate a mechanism for a subsequent
training-only candidate. A diagnostic cannot select/promote a model, change CRPS,
alter its normalization/aggregation or supply an extra penalty/weighted objective.
The user explicitly requires this separation. No new portfolio/data/score version
is implemented by this diagnostic.

Replay Public Adaptive(the worst of the three complete Public comparators under
both frozen profiles) and the exact current shrunk-mean winner on the existing245
development origins/49families/6classes. Use the original240 paths, native seed,
training prefix and financial forecast. Capture the daily forecast that the
unchanged native runner itself scores. Verify every entire CRPS loss-vector hash
against the preserved development reference, and recompute both canonical scalar
scores without any change. Diagnostic calculation happens afterward. No fit is
changed, no extra seed selected, and no model/financial candidate is admitted.

For each realized cumulative return compute the empirical ensemble CDF midpoint
(number strictly below + half equal)/240. Retain ten equal-width bins including
the endpoints, mean CDF midpoint and tie fraction. Quantiles use the generalized
inverse empirical CDF(order statistic ceil(240p), p=.05,.1,.25,.5,.75,.9,.95).
Record strict quantile exceedance and equality separately; central50/80/90percent
interval coverage includes both endpoints. Ties and a finite dependent,
stratified pool prevent treating this as an exact IID uniform-rank test. No formal
calibration/significance test or number of independent observations is claimed.

For descriptive horizon bands use the actual-calendar bands1–30,31–365,
366–1826,1827–7305,7306+days, plus all. Normalize the unchanged positive calendar
log weights within each available band, then apply the existing origin/series/
quarter/family/available-class hierarchy to diagnostic indicators. This creates
descriptive averages, NOT additional canonical scores or the earlier additive
CRPS-band decomposition. Report every band's matched origin count. Reused,
overlapping origins/horizons are adaptive development evidence, not independent
post-selection or arbitrary mixed-portfolio production validation.

Only compact per-origin indicators and aggregate reports are persisted. Full
forecast paths are streamed in bounded memory and regenerated by immutable
source/inputs/seeds; this does not pretend the original saved loss checkpoints
contained forecast paths. Native baselines and source/input provenance remain
necessary recovery parents. Source/model/scorer/plan/reference hashes freeze
before the first replay. Three numerical tests verify empirical-CDF endpoints,
ties/quantiles, scale/shift/path-permutation invariance, and calendar-band
normalization. A mismatch in any historical native loss hash fails closed.

Primary interpretation source: Gneiting,Balabdaoui,Raftery(2007), Probabilistic
forecasts, calibration and sharpness, JRSSB69:243–268,
https://doi.org/10.1111/j.1467-9868.2007.00587.x . This supports diagnostic
evaluation alongside proper scores; it does not prescribe our finite-ensemble
binning or benchmark aggregation as uniquely correct.
