# Training-adaptive stationary raw blocks

Keep the cohesive verified hybrid's equal mixture, symmetric per-asset GARCH fits, joint empirical residual rows, smooth mean treatment, correlated Gaussian mean uncertainty and portfolio accounting unchanged. Replace only the raw component's uniform circular blocks with a stationary bootstrap whose average block length is estimated exclusively from training data. Actual block lengths are geometric: each next simulated observation restarts at a uniformly chosen historical row with probability1/L; otherwise continue to the next historical row modulo training length. All constituents share each index.

Use the already installed scientific environment's arch8.0.0 corrected Politis–White/Patton–Politis–White selector, pinning its implementation digest in selector_provenance.json. Estimate stationary lengths for each active constituent's centered returns and centered-return squares; choose their maximum, constrained to1..training rows. Ignore exactly constant transformed columns since they contain no temporal variation. No threshold is calibrated to benchmark scores. The average length uses training history and is independent of forecast horizon, so at a fixed simulation seed the law has consistent horizon prefixes.

This mechanism interpolates between the rejected IID raw component and very long uniform blocks using a standard training dependence estimate, rather than another manually chosen length. An earlier research implementation supplied the underlying joint-asset PPW idea; no earlier-panel accuracy claim is required. The selector optimizes a bootstrap-inference approximation, not forecasting CRPS, so there is no presumed accuracy gain.
