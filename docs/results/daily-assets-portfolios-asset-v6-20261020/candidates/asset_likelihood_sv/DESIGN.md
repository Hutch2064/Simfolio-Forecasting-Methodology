# Likelihood-estimated latent volatility: controlled estimation contrast

The prior broad study's SV variants fit latent log-variance from proxy moments. This new family fits an AR(1) latent state to the same finite-at-zero log-square proxy by Gaussian measurement quasi-maximum likelihood. State persistence and stationary latent variance are training-fitted; the constant-variance boundary is explicitly eligible. Two optimizer starting points are numerical convergence checks, not forecast weights. Conditional log-square noise variance pi^2/2 is the theoretical Gaussian log-chi-square value. The proxy log(y^2+1/n), its training centering and the Gaussian measurement approximation remain modeling approximations; this is not exact stochastic-volatility maximum likelihood or a replica of M261.

The conditional return scale for historical innovation estimation uses the predicted state before the current observation. Fitted parameters still use the complete training prefix, as ordinary parameter fitting does. No data after the actual forecast date enters. The forecast state uses the final filtered training state advanced one step. A latent-state path variant and an analytic conditional-RMS variant share the same fitted parameters. Innovation alternatives are shared empirical asset rows, correlated Gaussian shocks and a finite-variance radial Student law with training-estimated tail parameter. Correlated mean uncertainty uses either the prior weighted batch estimator or the training-selected stationary-bootstrap mean covariance. All twelve are pure single generative models with no fixed component allocations.

Future joint asset paths and holdings use the unchanged numerical accounting kernels. Every declared path is scored. Parameters, law and source closure are frozen before the cheap 72-case screen. The fixed reference, panel, canonical overall score and stopping requirements remain unchanged. Low-path screens are exploratory. The screened data have been adaptively reused; no independence or significance claim. A candidate must improve appropriate matched1000-path representative checks before working-incumbent promotion; the final complete panel suite is launched only following the goal's evidence-based stopping review.

Methodological motivation: Ruiz (1994), Quasi-maximum likelihood estimation of stochastic volatility models, https://doi.org/10.1016/0304-4076(93)01569-8 ; Harvey, Ruiz and Shephard (1994), Multivariate stochastic variance models, https://shephard.scholars.harvard.edu/publications/multivariate-stochastic-variance-models . This adapter retains its stated proxy and cross-asset approximations and does not claim exact implementation of either paper.
