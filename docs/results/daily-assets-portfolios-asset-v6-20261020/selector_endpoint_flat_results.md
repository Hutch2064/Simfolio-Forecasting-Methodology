# Flattened adaptive selector: broader development evidence

The same 355 historical requests (70 distinct series) were evaluated at 1,000 final forecast paths. The flattened 167-recipe selector was tested with two and eight internal paths and three predeclared seeds, yielding 2,130 forecasts. Independent audit verified all forecast identities, source closures, loss hashes and canonical score calculations. There were no native forecast failures, scoring errors or infrastructure failures. All 432 matched losses from the preceding 72-request flat pilot replayed exactly.

The two-path version averaged main score 0.6834538600938401, 14.61120591395804% better than the fixed with-replacement asset baseline (0.8004022862826219). The eight-path version averaged 0.6880585852389401, 14.03590456562154% better. Prior nested-menu controls on identical coverage averaged 14.0787990170192% and 14.0344477684635% better respectively. These are reused development requests and repeated-seed descriptive results; no independent-validation, significance, full-panel or population win-rate claim is made. Official full-panel retained scores remain unchanged.

Flattening replaces the nested parent with its exact raw and filtered components in a single learned mixture. No arbitrary mixture percentage is introduced. Internal fits and selection use only historical prefixes available at the forecast date. The outer evaluation data never enter request-local fitting or weighting. The score and panel are unchanged.

The zero-weight pattern diagnostic decomposes the same score by portfolio, class and horizon. It does not set new selection rules. The slow-case profile identifies the numerical simplex mixture solver as the dominant cost in that one request; it does not establish a general speedup.
