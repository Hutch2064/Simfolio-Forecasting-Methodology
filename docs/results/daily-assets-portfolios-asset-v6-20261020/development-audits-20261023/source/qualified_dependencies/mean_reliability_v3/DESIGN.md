Reference loss is additionally multiplied by f=1/sqrt(1+h/n), suggested by the Gaussian IID sample-mean forecast-variance benchmark h+h²/n. This is a BENCHMARK HEURISTIC, not a universal uncertainty formula, effective-sample-size estimate, learned penalty, or likelihood. The weighted-mass normalization changes only the common objective scale relative to dividing by sum(m), not the exact minimizer; it matters for numerical conditioning and is explicitly frozen here.
