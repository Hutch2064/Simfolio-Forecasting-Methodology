# Frontier source parity

The Frontier implementation is a bounded extraction of the historical
2026-08-23 asset-level academic wrappers and the pinned source-research
engine revision `773bc1c325559e6bf57a567f1d8bf473a3427fbc`. The extraction is
kept under `models/numerical/`; the public model adapter is under
`models/asset_level/`. No source wrapper, service module, catalogue selector,
cache, memmap, or Student-t PGAS branch is copied into the package.

The historical marginal candidate retains the numerical FastMAP candidate
parameters, historical IDs, prior values, state-inference settings, leverage
alignment, BDES four-scale grid, raw empirical innovations,
conditional-Sharpe mean scaling, and return clipping. Deployment-only rollback
and promotion metadata is omitted. The marginal seed is

```
blake2b_8_le("asset_level_current_engine", ticker, origin_date,
             marginal_candidate_id, horizon_days, simulations)
```

The dependence layer retains the historical seed alias
`asset_level_exact_kalman_dynamic_gaussian_factor_rebalanced`, the exact
Gaussian dynamic factor fit, terminal information-form Kalman posterior, and
day-major Gaussian state projection. Marginals are rank-interpolated and
rejoined with the historical one-way 15 bps turnover cost. The portfolio
output is the daily rejoin return matrix; the caller owns terminal cumulative
sums and scoring.

The model requires all of the following: at least 80 finite aligned asset
observations, strict training dates, an origin date equal to the last training
date, strict future dates, and a future business-day calendar beginning on the
next business day. Unknown candidate settings and rebalance frequencies raise
an error. There is no fabricated date or generic fallback path.

The frozen fixture
`simfolio_forecasting_methodology/resources/test_fixtures/frontier/source_reference.npz` was
generated by those read-only wrappers on a deterministic 600-observation,
four-asset panel with 16 simulations and an eight-day horizon. It stores the
source posterior centers, BDES coefficients, marginal paths, factor fit,
Kalman state and covariance, Gaussian uniforms, and rejoined daily returns.
Its SHA-256 is
`d07ddf512332ad199dd48f233cdec13811a8d320f73e4b0b214aa9cbfd4591ae`.
The committed derived arrays were regenerated and tested under the shared
Python 3.11.15 environment with NumPy 2.4.6, SciPy 1.17.1, pandas 2.3.3, and
Numba 0.67.0. These versions are a reproducibility pin for the fixture; the
historical source runtime versions remain unverified.

The source rejoin/calendar fixture is
`simfolio_forecasting_methodology/resources/test_fixtures/frontier/rejoin_calendar_reference.npz`
with SHA-256
`178bf650aa3925467c52aefee74cd79036fdbb196c42f941b8a6928b8f21a965`.
It was generated from deterministic 5-by-80-by-4 float64 log paths using the
read-only source `_rebalanced_portfolio_log_paths_numba.py_func`, with masks
for `none`, `monthly`, `quarterly`, and `annually`; the fixture crosses the
September, October, November, and December 2026 boundaries and the 2027 year
boundary.

To regenerate it from the retained source copies, install the historical
wrapper dependencies, then run from the repository root:

```
PYTHONPATH=src NUMBA_DISABLE_CACHING=1 python3 tools/generate_frontier_rejoin_fixture.py \
  --source-research-root /path/to/source-research \
  --panel-root /path/to/asset_level_full_panel_20260823
```

The generator verifies the four recorded source SHA-256 values, writes no
source-side files, and emits the package resource consumed by the tests.
For the complete source fixture, run the following procedure with the
committed fixture as the frozen panel input:

```
PYTHONPATH=src NUMBA_DISABLE_CACHING=1 python3 tools/regenerate_frontier_source_fixture.py \
  --source-research-root /path/to/source-research \
  --panel-root /path/to/asset_level_full_panel_20260823 \
  --input-fixture src/simfolio_forecasting_methodology/resources/test_fixtures/frontier/source_reference.npz \
  --output /tmp/frontier-source-regenerated.npz
```

The regenerated file is byte-identical to the committed fixture under the
recorded source hashes. The script uses the original source FastMAP fitter and
simulator, exact Gaussian factor/Kalman helpers through their Python bodies to
avoid source cache writes, the original rank mapping, and the original 15 bps
rejoin. It does not import the extracted package to produce any derived array.

The focused parity test compares each of those numerical layers against the
fixture without importing the historical source tree. The observed source to
extraction tolerance on the reference probe was at most `4.34e-19` for the
marginal simulator and `2e-12` in the frozen-array tests. The extraction
digest command is `tools/extract_frontier_numeric.py`; when run with the
read-only source root it records AST digests and sanitized artifact names, and
without that root it records linkage as unverified.

## Remaining acceptance boundary

The historical source revision and the retained temporary wrapper hashes are
recorded, but the scored artifact's complete environment and original
registry-selection execution are not independently reproducible from this
package. The fixture proves bounded numerical parity for the extracted
closure; it does not prove that the public package alone recreates the full
historical scored 0.2557255171048505 artifact or the original data panel.
